# Web pública Pan y Esperanza

Sitio público oficial de la Asociación Pan y Esperanza.

Este proyecto es independiente del ERP. Solo se conecta al ERP mediante variables públicas de Supabase para leer métricas agregadas de impacto si las tablas o vistas públicas están disponibles.

## Comandos

```bash
npm run build
npm run preview
```

## Variables públicas

```bash
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
VITE_PLATFORM_URL=https://pan-y-esperanza.vercel.app
```
